# Nursultan script docs

Documentation for the Nursultan client's Kotlin scripting API, in two languages.

| | |
|---|---|
| [`en/`](en/README.md) | English |
| [`ru/`](ru/README.md) | Русский |

Each folder is a complete book: `README.md` is the landing page, `SUMMARY.md` is the table of contents, and `.gitbook.yaml` points GitBook at both.

The two trees are one document in two languages — a page added or changed in one is added or changed in the other, with the same headings in the same order.
