# Examples

Four complete scripts you can drop into the scripts folder as they are. Each one is a whole working file rather than a fragment, and each shows a different side of the API.

* [**MineBlaze auto duel**](mineblaze-auto-duel.md) — a chat packet answered with a command: the smallest useful shape for a server-specific script.
* [**Bridge builder**](bridge-builder.md) — movement prediction, a crosshair raycast and a borrowed hotbar slot.
* [**Auto soup**](auto-soup.md) — held slots, inventory batches, and staying out of the client's way.
* [**Anarchy helper**](anarchyhelper.md) — packets, a config, a command and notifications tied together.
