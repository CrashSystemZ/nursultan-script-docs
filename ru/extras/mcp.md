# MCP для ИИ-агентов

Клиент умеет отдавать свой скриптовый рантайм как MCP-сервер: агент заливает, включает, настраивает и читает
скрипты. По умолчанию он выключен и включается во вкладке «Скрипты». Про сам API — вся остальная документация,
начиная с [Первого скрипта](../start/first-script.md) и [Песочницы и лимитов](limits.md).

## Как включить

Открой вкладку **Скрипты**, нажми кнопку **MCP** в шапке — слева от кнопки консоли — и поставь галочку
**Включён**. Уведомление скажет, поднялся сервер или нет; при успехе ссылка уже лежит в буфере обмена, а кнопка
в шапке подсвечена, пока сервер работает.

| Элемент | Что делает |
|---|---|
| `Включён` | запускает и останавливает сервер; сохраняется и восстанавливается при следующем запуске |
| `Копировать` | кладёт текущую ссылку в буфер обмена |
| `Новый токен` | выпускает новый 32-байтный токен и перезапускает; старая ссылка сразу перестаёт работать |
| `Новый порт` | берёт свободный порт и перезапускает; ссылка меняется |

Последние три появляются только пока сервер работает. Ссылка — `http://127.0.0.1:<port>/mcp/<token>`; порт и
токен сохраняются, так что между запусками она не меняется.

Сервер слушает только `127.0.0.1` и говорит JSON-RPC поверх HTTP POST (протокол MCP `2025-06-18`, лимит тела
1 МиБ); токен в пути — единственная проверяемая учётка, а запрос с заголовком `Origin` или с чужим `Host`
получает 404.

Отдай ссылку агенту:

```bash
claude mcp add --transport http nursultan http://127.0.0.1:PORT/mcp/TOKEN
```

## Инструменты

| Инструмент | Аргументы | Возвращает |
|---|---|---|
| `scripts_list` | — | `scriptsDir`, `assetsDir` и по каждому скрипту `id`, `file`, `name`, `description`, `enabled`, `status` (`LOADING`/`WAITING`/`READY`/`ERROR`), `phase` (`Reading`/`Compiling`/`Starting`, пропадает после загрузки), `error` |
| `script_source` | `id` | `id`, `file`, `source` |
| `script_deploy` | `name` (1..48 символов из `A-Za-z0-9 _-`), `source` (до 256 КиБ) | пишет `<name>.kts` в папку скриптов; `written`, `bytes` |
| `script_delete` | `id` | выгружает скрипт и удаляет его файл; `unloaded`, `deleted` |
| `script_enable` | `id` | включает скрипт, как нажатие его бинда; `enabled` |
| `script_disable` | `id` | выключает скрипт; `enabled` |
| `script_settings` | `id` | `id`, `name`, `enabled`, `status`, `bind` и все настройки |
| `script_setting_set` | `id`, `key`, `value` | пишет одну настройку; `kind` плюс весь список `settings` |
| `script_bind_set` | `id`, `key` (`UNKNOWN` снимает бинд), `mods` (маска GLFW, 0 если не передан) | перевешивает бинд; новый `bind` |
| `console_tail` | `sinceId` (без него — весь буфер), `limit` (по умолчанию 200, не больше буфера в 1000 строк) | `lines` из `id`, `time`, `level` (`INFO`/`WARN`/`ERROR`), `text`, плюс `lastId`, `revision`, `dropped` |
| `game_state` | — | `inGame`, `singleplayer`, `server`, а в мире ещё `dimension`, `x`, `y`, `z`, `username` |

Играть эти инструменты не умеют: ничего из перечисленного не двигает игрока, не открывает экраны и не кликает по
блокам. Все инструменты, кроме `scripts_list`, `script_source` и `script_deploy`, выполняются на клиентском
потоке и падают через 5 с, если клиент не ответил.

`script_deploy` только пишет файл — перекомпиляцию запускает вотчер сам, поэтому результат виден в следующем
`scripts_list`. `console_tail` инкрементальный: передавай прошлый `lastId` как `sinceId`; `sinceId` больше самого
свежего id отдаёт весь буфер и `reset: true`, потому что нумерация строк начинается заново вместе с клиентом.

## Формы значений настроек

`script_settings` отдаёт у каждой настройки `kind`, а `script_setting_set` ждёт значение под этот вид.

| Вид | Что слать |
|---|---|
| `checkbox` | `true` / `false` |
| `slider` | число; в отчёте есть `min`, `max`, `step` |
| `rangeSlider` | `{"min": 1, "max": 4}`; в отчёте есть `limitMin`, `limitMax`, `step` |
| `input` | строку; в отчёте есть `placeholder`, если он задан |
| `colorPicker` | целое ARGB |
| `selectable` | `name` одного варианта, регистр не важен |
| `combo` | массив имён вариантов; всё, чего в нём нет, снимается |
| `hotkey` | `"G"` или `{"key": "G", "mods": 2}`; `mods` — битовая маска GLFW |
| `button` | что угодно; отправка нажимает кнопку |
| `group` | ничего — у группы нет значения, запись падает |

У каждой настройки в отчёте есть `key`, `label`, `kind`, `visible`, `modified` и `value`; вложенная добавляет
`parent` и адресуется ключом через точку (`Toggle.Only when toggled`) и на чтение, и на запись.

Объекты и массивы принимаются и настоящим JSON, и строкой с JSON внутри; имена вариантов берутся из
`options[].name`, а не из `label`.
