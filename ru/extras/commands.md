# Свои команды

`command("name") { }` регистрирует команду клиента с префиксом `.`, живущую ровно столько, сколько скрипт включён. Аргументы — это сырой хвост после пути узла, разбитый по пробельным промежуткам.

```kotlin
command("home") {
    usage("<go|list>")
    alias("h")
    sub("go") {
        completes(0, "base", "farm")
        runs { reply("going to " + arg(0)) }
    }
}
```

## Объявление

| Метод | Тип | Описание |
|---|---|---|
| `command(name) { }` | `Subscription` | регистрирует команду и её алиасы (кидает `ScriptException`, если имя пустое, из нескольких слов, занято командой клиента или другим скриптом, либо у команды нет ни `runs`, ни `sub`) |
| `usage(text)` | `Unit` | текст подсказки, дописываемый к ошибке о нехватке аргумента, null становится `""` |
| `alias(name)` | `Unit` | дополнительное имя того же дерева команд (кидает `ScriptException`, если пустое, из нескольких слов или занято) |
| `runs { }` | `Unit` | тело, вызываемое на клиентском потоке при вызове узла, исключения логируются |
| `sub(name) { }` | `Unit` | подкоманда, вложенность не ограничена, имя приводится к одному слову в нижнем регистре |
| `completes(argIndex, options)` | `Unit` | поставщик подсказок для аргумента с индексом от 0, фильтр по префиксу без учёта регистра (кидает `ScriptException` при argIndex < 0) |
| `completes(argIndex, vararg options)` | `Unit` | фиксированный список подсказок для этого аргумента |

Имя обрезается по краям, приводится к нижнему регистру и теряет один ведущий символ префикса; пока скрипт выключен, команда не отвечает и пропадает из подсказок, но имя остаётся за ней.
Поставщик подсказок вызывается, пока игрок печатает; исключение внутри него логируется, и вариантов не будет.

## Java-билдер

| Метод | Тип | Описание |
|---|---|---|
| `client.commands().command(name)` | `CommandBuilder` | начинает описание команды (кидает `ScriptException`, если имя пустое или содержит пробел) |
| `client.commands().prefix()` | `String` | префикс команд клиента одним символом, по умолчанию `.` |
| `usage(usage)` | `CommandBuilder` | текст подсказки, дописываемый к ошибке о нехватке аргумента, null становится `""` |
| `alias(alias)` | `CommandBuilder` | дополнительное имя того же узла (кидает `ScriptException` на пустом или многословном алиасе) |
| `runs(handler)` | `CommandBuilder` | обработчик, вызываемый на клиентском потоке (кидает `ScriptException` на null-обработчике) |
| `sub(name, body)` | `CommandBuilder` | создаёт или дополняет подкоманду (кидает `ScriptException` на пустом имени или null-теле) |
| `completes(argIndex, options)` | `CommandBuilder` | поставщик подсказок для аргумента с индексом от 0 (кидает `ScriptException` при argIndex < 0 или null options) |
| `completes(argIndex, options...)` | `CommandBuilder` | фиксированный список подсказок, null-массив означает отсутствие вариантов |
| `register()` | `Subscription` | регистрирует имя и все алиасы (кидает `ScriptException`, если у узла нет ни `runs`, ни `sub`, имя занято командой клиента или другим скриптом) |

До `register()` ничего не регистрируется; Kotlin-форма `command(name) { }` вызывает его сама.
`unsubscribe()` у возвращённой подписки снимает и имя, и все алиасы — [Подписка на события](../events/basics.md).

## Внутри `runs`

Получатель — `CommandContext`.

| Метод | Тип | Описание |
|---|---|---|
| `label()` | `String` | полный путь узла, например `home go` |
| `args()` | `List<String>` | аргументы после пути узла |
| `argCount()` | `int` | количество аргументов |
| `arg(index)` | `String` | аргумент по индексу от 0 (кидает `ScriptException` с номером позиции и текстом usage, если его нет) |
| `argOr(index, fallback)` | `String` | аргумент или fallback, если индекс за пределами |
| `intArg(index)` | `int` | аргумент как int (кидает `ScriptException`, если его нет или это не целое число) |
| `doubleArg(index)` | `double` | аргумент как double (кидает `ScriptException`, если его нет или это не число) |
| `booleanArg(index)` | `boolean` | принимает true/on/yes/1 и false/off/no/0 без учёта регистра (иначе кидает `ScriptException`) |
| `rest()` | `String` | весь хвост аргументов одной строкой |
| `rest(fromIndex)` | `String` | аргументы с этого индекса через один пробел, весь хвост при fromIndex <= 0, `""` за концом |
| `reply(message)` | `void` | пишет `[<label>] message` в твой чат |
| `replyError(message)` | `void` | вывод точно как у `reply`, отдельного оформления нет |
