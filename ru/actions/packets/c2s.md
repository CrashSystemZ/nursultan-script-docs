# Пакеты, которые можно отправить

65 записей к серверу; каждая — Java-запись: собираешь её каноническим конструктором и отдаёшь в `packets.send` или `packets.sendSequenced` — смотри [Пакеты](../packets.md#отправить). 14 из них только для наблюдения: `send` возвращает `false` и один раз пишет предупреждение в консоль скриптов. Отправка срывается и на null-поле, и на константе enum без ванильной пары, и на сущности вне загруженного мира, и на слоте вне диапазона; сами перечисления — на странице [Перечисления пакетов](enums.md).

```kotlin
name("Instant respawn")
key(Key.R)

onEnable {
    // кнопка «Возродиться» с экрана смерти, но пакетом
    packets.send(C2SClientStatusPacket(ClientStatus.PERFORM_RESPAWN))
}
```
