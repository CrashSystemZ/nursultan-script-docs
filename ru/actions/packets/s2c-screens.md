# Пакеты экранов и чата

Записи от сервера про обработчики экранов, инвентари, сделки, книгу рецептов, чат, титры, таблист, табло и служебные сообщения соединения. Все 63 приходят в `PacketReceiveEvent` и не отправляются: текст в них — обычная строка, предмет — id и количество, а поле-перечисление равно `null`, когда у ванильной константы нет одноимённой пары — [Пакеты](../packets.md).

```kotlin
on<PacketReceiveEvent> { e ->
    val packet = e.packet()
    if (packet !is S2CScreenHandlerSlotUpdatePacket) return@on
    if (packet.item() == "minecraft:air") return@on

    log.info("slot ${packet.slot()}: ${packet.item()} x${packet.count()}")
}
```

## S2CAdvancementUpdatePacket

Синхронизация списка достижений; карты полученного и прогресса, а также данные отображения не раскрыты.

| Поле | Тип | Описание |
|---|---|---|
| `clearCurrent()` | `boolean` | заменить весь набор достижений, а не дополнить |
| `toRemove()` | `List<String>` | id удаляемых достижений |
| `showToast()` | `boolean` | показать всплывашку о новых достижениях |

## S2CTeamPacket

Команда табло создана, обновлена или удалена, либо в неё добавили и из неё убрали участников.

| Поле | Тип | Описание |
|---|---|---|
| `teamName()` | `String` | внутреннее имя команды |
| `playerNames()` | `List<String>` | затронутые участники, пусто при чистом обновлении команды |
| `teamOperation()` | `TeamOperation?` | что происходит с самой командой |
| `playerListOperation()` | `TeamPlayerListOperation?` | что происходит со списком участников |
| `displayName()` | `String?` | отображаемое имя команды обычным текстом |
| `prefix()` | `String?` | префикс ника обычным текстом |
| `suffix()` | `String?` | суффикс ника обычным текстом |
| `friendlyFlags()` | `Integer?` | битовая маска, 1 — урон своим, 2 — видеть невидимых своих |
| `color()` | `Formatting?` | код цвета команды |
| `nameTagVisibilityRule()` | `TeamVisibilityRule?` | когда видны ники |
| `collisionRule()` | `TeamCollisionRule?` | когда сущности сталкиваются |

Семь полей начиная с `displayName()` равны null, если пакет не несёт данных команды, то есть везде кроме создания и обновления.
