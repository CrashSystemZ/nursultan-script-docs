# Пакеты сущностей

Записи от сервера про сущности и своего игрока: появление, движение, поворот, скорость, урон, эффекты, экипировка, атрибуты и данные трекера. Позиции — блоки мира, скорости — блоки за тик, повороты — градусы, длительности — тики; про потоки, отмену и то, что теряется при декодировании, — [Пакеты](../packets.md).

```kotlin
on<PacketReceiveEvent> { e ->
    val packet = e.packet()
    if (packet !is S2CEntityVelocityPacket) return@on
    if (packet.entityId() != player.id()) return@on

    log.info("knockback ${packet.velX()} ${packet.velZ()}")
}
```

## S2CEntityAttributesPacket

Базовые значения атрибутов и модификаторы одной сущности.

| Поле | Тип | Описание |
|---|---|---|
| `entityId()` | `int` | сетевой id сущности |
| `attributes()` | `List<Attribute>` | записи атрибутов |

`S2CEntityAttributesPacket.Attribute`

| Поле | Тип | Описание |
|---|---|---|
| `attribute()` | `String` | id атрибута с пространством имён, напр. `minecraft:movement_speed` |
| `base()` | `double` | базовое значение до модификаторов |
| `modifiers()` | `List<Modifier>` | модификаторы этого атрибута |

`S2CEntityAttributesPacket.Modifier`

| Поле | Тип | Описание |
|---|---|---|
| `id()` | `String` | id модификатора с пространством имён |
| `value()` | `double` | величина модификатора |
| `operation()` | `String` | ванильная операция в нижнем регистре, напр. `add_value`, `add_multiplied_base` |

## S2CEntityDamagePacket

Урон по сущности. Тип урона и величина не раскрыты.

| Поле | Тип | Описание |
|---|---|---|
| `entityId()` | `int` | сетевой id пострадавшей сущности |
| `sourceCauseId()` | `int` | сетевой id атакующего, 0 если его нет |
| `sourceDirectId()` | `int` | сетевой id прямого источника, включая снаряд, 0 если его нет |
| `sourceX()` | `Double?` | x источника урона в мире, null у большинства источников |
| `sourceY()` | `Double?` | y источника урона в мире, null у большинства источников |
| `sourceZ()` | `Double?` | z источника урона в мире, null у большинства источников |

## S2CPlayerPositionLookPacket

| Поле | Тип | Описание |
|---|---|---|
| `teleportId()` | `int` | id, который надо вернуть в подтверждении |
