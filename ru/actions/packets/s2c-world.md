# Пакеты мира

Записи от сервера про блоки, чанки, свет, границу мира, время, погоду, звуки, частицы и взрывы. Каждая приходит через `PacketReceiveEvent.packet()`; позиции — в блоках, координаты чанков — блоки/16, повороты — в градусах, тики идут по 20 в секунду; про потоки, отмену и то, что теряется при разборе, — в [Пакетах](../packets.md).

```kotlin
on<PacketReceiveEvent> { e ->
    val packet = e.packet()
    if (packet !is S2CBlockUpdatePacket) return@on

    // где-то блок стал воздухом
    if (packet.block() == "minecraft:air") log("${packet.x()} ${packet.y()} ${packet.z()}")
}
```

## S2CBlockBreakingProgressPacket

Полоса разрушения блока, который ломает другая сущность.

| Поле | Тип | Описание |
|---|---|---|
| `entityId()` | `int` | сетевой id ломающей сущности |
| `x()` | `int` | x блока |
| `y()` | `int` | y блока |
| `z()` | `int` | z блока |
| `progress()` | `int` | стадия 0..9, всё вне диапазона снимает полосу |

## S2CBlockEntityUpdatePacket

Данные блок-сущности в одной позиции.

| Поле | Тип | Описание |
|---|---|---|
| `x()` | `int` | x блока |
| `y()` | `int` | y блока |
| `z()` | `int` | z блока |
| `type()` | `String` | id типа блок-сущности с неймспейсом |
| `nbt()` | `String` | SNBT-нагрузка, `""` когда её в пакете не было |

## S2CBlockEventPacket

Действие блока — нотный блок, крышка сундука, поршень, колокол.

| Поле | Тип | Описание |
|---|---|---|
| `x()` | `int` | x блока |
| `y()` | `int` | y блока |
| `z()` | `int` | z блока |
| `type()` | `int` | id действия, свой у каждого блока |
| `data()` | `int` | параметр действия, свой у каждого блока |
| `block()` | `String` | id блока с неймспейсом, к которому идёт действие |

## S2CBlockUpdatePacket

Смена одного блока; из состояния доступен только id блока.

| Поле | Тип | Описание |
|---|---|---|

| `y()` | `int` | y блока |
| `z()` | `int` | z блока |
| `block()` | `String` | id нового блока с неймспейсом |

## S2CChunkBiomeDataPacket

Повторная отправка только биомов чанка; полей нет.

## S2CChunkDataPacket

Полная отправка чанка; секции, блок-сущности, карты высот и свет не раскрыты.

| Поле | Тип | Описание |
|---|---|---|
| `chunkX()` | `int` | x чанка, блоки/16 |
| `chunkZ()` | `int` | z чанка, блоки/16 |

## S2CChunkDeltaUpdatePacket

Несколько изменений блоков внутри одной секции 16x16x16.

| Поле | Тип | Описание |
|---|---|---|
| `blocks()` | `List<BlockChange>` | изменённые блоки, позиции уже абсолютные |

### S2CChunkDeltaUpdatePacket.BlockChange

Одно изменение блока внутри дельта-обновления чанка.

| Поле | Тип | Описание |
|---|---|---|

| `y()` | `int` | абсолютный y блока |
| `z()` | `int` | абсолютный z блока |
| `block()` | `String` | id нового блока с неймспейсом |
| `air()` | `boolean` | новое состояние — воздух |

## S2CExplosionPacket

Эффект взрыва; тип частиц, звук и список разрушенных блоков не раскрыты.

| Поле | Тип | Описание |
|---|---|---|

| `y()` | `double` | y центра взрыва в блоках |
| `z()` | `double` | z центра взрыва в блоках |
| `radius()` | `float` | радиус взрыва в блоках |
| `blockCount()` | `int` | сколько блоков разрушено |
| `knockbackX()` | `double` | отбрасывание игрока по x в блоках/тик, 0 если его нет |
| `knockbackY()` | `double` | отбрасывание игрока по y в блоках/тик, 0 если его нет |
| `knockbackZ()` | `double` | отбрасывание игрока по z в блоках/тик, 0 если его нет |

## S2CGameJoinPacket

| Поле | Тип | Описание |
|---|---|---|
| `playerEntityId()` | `int` | сетевой id локального игрока |
| `hardcore()` | `boolean` | хардкорный мир |
| `dimensionIds()` | `List<String>` | id всех измерений сервера с неймспейсами |
| `maxPlayers()` | `int` | заявленное число слотов |
| `viewDistance()` | `int` | дальность прогрузки сервера в чанках |
| `simulationDistance()` | `int` | дальность симуляции сервера в чанках |
| `reducedDebugInfo()` | `boolean` | экран F3 урезан |
| `showDeathScreen()` | `boolean` | показывать экран смерти вместо мгновенного респавна |
| `doLimitedCrafting()` | `boolean` | крафт требует разблокировки в книге рецептов |
| `enforcesSecureChat()` | `boolean` | сервер требует подписанный чат |

## S2CMapUpdatePacket

Обновление заполненной карты; пиксели, значки и обновлённый прямоугольник не раскрыты.

| Поле | Тип | Описание |

## S2CParticlePacket

Запрос на спавн частиц; тип частицы и её параметры не раскрыты.

| Поле | Тип | Описание |
|---|---|---|
| `x()` | `double` | x центра спавна в блоках |
| `y()` | `double` | y центра спавна в блоках |
| `z()` | `double` | z центра спавна в блоках |
| `offsetX()` | `float` | гауссов разброс по x в блоках |
| `offsetY()` | `float` | гауссов разброс по y в блоках |
| `offsetZ()` | `float` | гауссов разброс по z в блоках |
| `speed()` | `float` | множитель скорости частиц |
| `count()` | `int` | количество частиц; 0 превращает разбросы в скорость |
| `forceSpawn()` | `boolean` | игнорирует клиентский лимит дальности частиц |
| `important()` | `boolean` | спавнится даже на минимальной настройке частиц |
