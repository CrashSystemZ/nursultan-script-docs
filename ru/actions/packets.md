# Пакеты

Событие пакета отдаёт один протокольный пакет Minecraft, разобранный в Java-запись. События пакетов приходят на сетевом потоке, а не на клиентском, и запись — плоский снимок: декодирование пережило только то, что видно в её аксессорах.

```kotlin
on<PacketReceiveEvent> { e ->
    val packet = e.packet()
    if (packet !is S2CGameMessagePacket || packet.overlay()) return@on
    if (!packet.content().contains("duel")) return@on

    onClientThread { chat.sendToServer("/next") }
}
```

## Два потока

| Метод | Тип | Описание |
|---|---|---|
| `onClientThread(action)` | `Unit` | ставит действие в очередь на клиентский поток, пропускается, если скрипт к тому моменту выключен — [Таймеры и задачи](../extras/tasks.md#перейти-на-клиентский-поток) |
| `client.onClientThread()` | `boolean` | true, когда вызов уже идёт на клиентском потоке — [Таймеры и задачи](../extras/tasks.md#перейти-на-клиентский-поток) |

Читать аксессоры записи вне клиентского потока безопасно.
`interaction`, `raycast`, `rotations.apply`, изменения инвентаря и контейнера, `world.blockEntitiesIn` и `world.removeEntity` бросают там `ScriptThreadException`, а `packets.send` возвращает `false`.

## Приём

| Метод | Тип | Описание |
|---|---|---|
| `PacketReceiveEvent.packet()` | `S2CPacket` | разобранный пакет от сервера, в обработчике никогда не null — [Список событий](../events/reference.md) |
| `PacketSendEvent.packet()` | `C2SPacket` | разобранный пакет к серверу, в обработчике никогда не null — [Список событий](../events/reference.md) |

До обработчика доходят только пакеты, для которых у клиента есть декодер; остальные не порождают события вовсе, а сбой декодирования пишется в лог один раз на класс пакета.
Внутри бандла каждый вложенный пакет приходит отдельно.

| Метод | Тип | Описание |
|---|---|---|
| `Packet` | `interface` | корневой маркер любой записи пакета, членов не объявляет |
| `S2CPacket` | `interface` | маркер пакетов от сервера, наследует `Packet` |
| `C2SPacket` | `interface` | маркер пакетов к серверу, наследует `Packet`; именно его принимает `send` |

`nursultan.packet.*`, `nursultan.packet.c2s.*` и `nursultan.packet.s2c.*` импортированы по умолчанию, поэтому строка `import` для записей и перечислений не нужна.

## Отмена

| Метод | Тип | Описание |
|---|---|---|
| `PacketReceiveEvent.cancel()` | `void` | Minecraft этот пакет не обработает |
| `PacketSendEvent.cancel()` | `void` | пакет не уйдёт с клиента |

Отмена вложенного пакета внутри бандла убирает его из бандла.
Оба события полностью игнорируют `EventOptions` — и `priority`, и `ignoreCancelled`.

## Отправить

| Метод | Тип | Описание |
|---|---|---|
| `packets.send(packet)` | `boolean` | отправляет запись как ванильный пакет; false вне клиентского потока, без игрока или сетевого обработчика, на null и на записи только для наблюдения, а также когда поле не удалось преобразовать (только клиентский поток) |
| `packets.sendSequenced(packet)` | `boolean` | отправляет через менеджер взаимодействия, который проставляет серверный номер; те же условия false плюс отсутствующие мир или менеджер взаимодействия (только клиентский поток) |

`packets` — это `game.packets()`; отклонённая отправка пишет предупреждение в консоль скриптов один раз на класс пакета. `send` переиспользует поле `sequence` самой записи, `sendSequenced` его заменяет.
Отправленный из скрипта пакет уходит через тот же вызов соединения, поэтому снова приходит в `PacketSendEvent`.

## Что теряется

| Тип Minecraft | В записи | Примечание |
|---|---|---|
| `ItemStack` | `String` + `int` | id из реестра и количество; зачарований, компонентов и NBT нет |
| `Text` | `String` | обычный текст из `getString()`, без цветов, стилей и кликов |
| `Identifier` | `String` | `namespace:path` |
| `UUID` | `String` | `toString()` |
| `NbtCompound` | `String` | текст SNBT, `""` когда в пакете его не было |
| константа enum | скриптовый enum | сопоставляется по имени константы — [Перечисления пакетов](packets/enums.md) |

Ванильная константа без пары в скриптовом enum декодируется в `null` и пишет одно предупреждение; скриптовая константа без ванильной пары срывает всю отправку.
Полные предметы, компоненты и подписи доступны только через мир и [Инвентарь и предметы](../game/inventory.md), из пакета — никогда.

Записи пакетов повторяют протокол Minecraft той версии клиента, с которой поставляются (1.21.11), — это единственная часть API, привязанная к версии игры: обновление Minecraft может переименовать запись или изменить её поля.
Клиент переписывает `.sdk/` при каждом запуске, поэтому джарка пакетов всегда соответствует клиенту, под который ты пишешь.
