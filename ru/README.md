# Что это

Скрипты Nursultan — это обычные Kotlin-файлы с расширением `.kts`, которые клиент компилирует прямо во время игры. Сохранил файл — скрипт перезагрузился, перезапускать клиент не нужно.

Один файл — один скрипт. Вот целиком рабочий скрипт:

```kotlin
name("Hello")
description("Мой первый скрипт")

chat.print("привет")

on<ClientTickEvent> {
    // выполняется каждый игровой тик, пока скрипт включён
}
```

## Что можно сделать

* **Свой модуль** — настройки, бинд, переключатель во вкладке Scripts. Смотри [Как устроен скрипт](start/lifecycle.md) и [Виды настроек](settings/types.md).
* **Реакции на игру** — тики, урон, атаки, ввод, пакеты, появление сущностей и т.д. Смотри [События](events/basics.md).
* **Чтение мира** — игрок, блоки, сущности, инвентарь, сервер и т.д. Смотри [Игровые данные](game/player.md).
* **Действия** — бить, ставить, ломать, крутить голову, менять слоты, слать пакеты и т.д. Смотри [Действия](actions/interaction.md).
* **Своя графика** — HUD, боксы и линии в мире, свои шейдеры и т.д. Смотри [Интерфейс](ui/render-2d.md).
* **Свои команды** — с подсказками по Tab, как у команд самого клиента и т.д. Смотри [Свои команды](extras/commands.md).

## Где лежат скрипты

`%APPDATA%\Nursultan\scripts`

В этой папке лежат **только** готовые `.kts`. Писать скрипты удобнее в отдельной папке-проекте — как её открыть в IDE, написано в [Проект в IDE](start/ide.md).

Всё, что скрипт читает — шрифты, картинки, данные, — лежит папкой ниже, в `scripts\assets`. Смотри [Папка assets](extras/assets.md).

Имя файла — идентификатор скрипта: `auto-jump.kts` появится в меню как `auto-jump`, пока не зададите ему `name(...)`.

## Вкладка Scripts

Всё управление — во вкладке **Scripts** в меню клиента.

* Пока идёт компиляция, карточка скрипта неактивна. Ошибка подсветит её красным и покажет текст.
* У каждого скрипта своя карточка: **переключатель** — включить/выключить, **точки или ПКМ** — настройки, **иконка клавиатуры или СКМ** — назначить бинд.
* Состояние переживает перезапуск: включённость, бинд и настройки восстановятся сами.
