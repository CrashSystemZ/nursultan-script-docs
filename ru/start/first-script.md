# Первый скрипт

Имя файла без `.kts` — это id скрипта; всё, что написано на верхнем уровне, выполняется один раз при загрузке, а обработчики `on<...>` работают только пока скрипт включён.

```kotlin
name("Auto jump")
key(Key.G)
val delay by slider("Delay", 5, 1, 20)
var ticks = 0
onEnable { ticks = 0 }
on<ClientTickEvent> {
    if (++ticks < delay) return@on
    ticks = 0
    whenInGame { control.jump() }
}
```

## Самый маленький файл

| Факт | Подробности |
|---|---|
| файл | любой `.kts` в папке скриптов, `*.gradle.kts` игнорируется |
| id скрипта | имя файла без `.kts`, ключ для конфигов и пресетов |
| пустой файл | компилируется, появляется во вкладке Scripts, ничего не делает |
| подпись в меню | `name(...)`, если задан, иначе id скрипта |
| сохранение файла | пересобирает скрипт, возвращает бинд и состояние вкл/выкл |

## Настройки и бинд

| Что | Где описано |
|---|---|
| `checkBox`, `slider`, `input`, `selectable`, `combo`, `colorPicker`, `hotkey`, `button` | [Виды настроек](../settings/types.md) |
| `name`, `description`, `key`, `bind`, `onEnable`, `onDisable` | [Как устроен скрипт](lifecycle.md) |
| `on<E> { }`, `ignoreCancelled`, `unsubscribe()` | [Подписка на события](../events/basics.md) |

## Чтение настройки

| Объявление | Тип | Описание |
|---|---|---|
| `val delay by slider("Delay", 5f, 1f, 20f)` | `Float` | делегат, читает живое значение при каждом обращении |
| `val delay = slider("Delay", 5f, 1f, 20f)` | `Slider` | сам объект настройки: `value()`, `onChange`, `visibleWhen` |

`var x by ...` ещё и пишет: присваивание свойству вызывает сеттер настройки. Тип делегата у каждого вида настройки — [Виды настроек](../settings/types.md).

## Куда уходят ошибки

| Куда | Что туда попадает |
|---|---|
| консоль скриптов | ошибки компиляции, падения обработчиков как `failed - <file>.kts:<line>: <message>`, `log.info/warn/error` |
| чат | только то, что скрипт сам печатает через `chat.print` |
| лог клиента | каждая строка консоли, продублированная в лог Minecraft |

Повторные падения дросселируются до одного отчёта раз в 3000 мс на скрипт, а 5 падений подряд выключают скрипт — [Песочница и лимиты](../extras/limits.md). Вывод в консоль и чат — [Сообщения](../ui/messages.md).
