# Проект в IDE

Папка для разработки скриптов с сайта (`nursultan-scripts-v5.zip`) распаковывается в `nursultan-scripts/` — готовый проект IntelliJ IDEA: джарки API, сборочные файлы и пример скрипта. Если это папка скриптов клиента, клиент обновляет `.sdk/` и оба сборочных файла при каждом запуске.

## Что скачать

| Путь | Что это |
|---|---|
| `example.kts` | пример скрипта; каждый `.kts` в корне папки — отдельный скрипт |
| `assets/` | шрифты, картинки и данные, которые читают скрипты — см. [папку assets](../extras/assets.md) |
| `.sdk/nursultan-script-api-v<N>.jar` | само API и определение `.kts`; `<N>` — версия script API клиента, сейчас 7 |
| `.sdk/nursultan-script-packets-<mcVersion>.jar` | классы пакетов Minecraft, нужны только скриптам, которые их читают или шлют; суффикс — версия Minecraft клиента |
| `build.gradle.kts`, `settings.gradle.kts` | подключают джарки из `.sdk` и Kotlin-скриптинг |
| `README.md` | те же шаги офлайн |

`.sdk/` — сгенерированная папка: клиент перезаписывает джарки и удаляет все `nursultan-script-*.jar` от других версий. Файлы переписываются, только если изменились байты, так что при неизменном SDK Gradle не пересинкается.

## Открыть в IntelliJ IDEA

1. `File → Open`, выбери папку, «Open as Project», доверь проект.
2. Gradle синкается один раз и тянет Kotlin-плагин, `kotlin-scripting-jvm` и `kotlin-scripting-common` с Maven Central.
3. В проекте стоит `jvmToolchain(21)`, поэтому Gradle нужен JDK 21.

## Определение скрипта

**Settings → Languages & Frameworks → Kotlin → Kotlin Scripting** → *Custom Definitions* → **Search Definitions** → в списке появится **Nursultan Script** (`.kts`) → оставь включённым и **выше** *Default Kotlin Script* → **Apply**.

IntelliJ не находит кастомные определения скриптов сам: пока это не применено, любой `.kts` красный. Резолв считается по файлу, так что после применения открой скрипт заново.

## Перенос в игру

1. Скопируй `.kts` в `%APPDATA%\Nursultan\scripts`; имя файла без `.kts` — это id скрипта.
2. Скопируй шрифты, картинки и данные, которые он читает, в `%APPDATA%\Nursultan\scripts\assets`, сохранив подпапки из проекта.
3. Включи скрипт во вкладке Scripts.

`.sdk/` и сборочные файлы остаются на месте — клиент их не читает. Сохранение уже загруженного файла перекомпилирует и перезагружает скрипт прямо в игре.

## Разработка в игровой папке

`%APPDATA%\Nursultan\scripts` считается проектом, если в ней лежит `build.gradle.kts` или папка `.sdk/`; положи туда всю папку разработки и открой этот путь в IDEA. Тогда при каждом запуске клиент пересобирает джарки `.sdk` из самого себя и переписывает `build.gradle.kts` и `settings.gradle.kts`, так что SDK не отстаёт от клиента. Если нет ни `build.gradle.kts`, ни `.sdk/`, клиент папку не трогает.
