# Примеры

Четыре готовых скрипта, которые можно положить в папку скриптов как есть. Каждый — целый рабочий файл, а не кусок, и каждый показывает свою сторону API.

* **Автодуэль на MineBlaze** — чат-пакет, на который отвечают командой: самая маленькая полезная форма скрипта под конкретный сервер.
* **Строитель мостов** — предсказание движения, рейкаст из прицела и одолженный слот хотбара.
* **Автосуп** — удержанные слоты, инвентарные батчи и умение не лезть клиенту под руку.
* **Помощник на анархии** — пакеты, конфиг, команда и уведомления в одном скрипте.
