# Оформленный текст

`text` — это `client.text()`. Каждый вызов оформления меняет сам объект и возвращает его же, поэтому `Text` одновременно и построитель, и значение — развилку можно сделать только через `copy()`.

```kotlin
chat.print(
    text.literal("[teleport]")
        .color(Colors.CYAN)
        .bold(true)
        .runCommand("/spawn")
        .hoverText("go to spawn")
)
```

## Как собрать

| Метод | Тип | Описание |
|---|---|---|
| `text.literal(value)` | `Text` | литеральный компонент; null становится `""` |
| `text.empty()` | `Text` | пустой компонент, годится как корень для append |
| `text.translatable(key, args...)` | `Text` | компонент перевода; аргументы-`Text` разворачиваются (бросает `ScriptException` на пустом ключе) |
| `text.keybind(key)` | `Text` | показывает клавишу, забинденную на ванильный keybind id (бросает `ScriptException` на пустом ключе) |
| `text.legacy(value)` | `Text` | разбирает `§`-коды в стилизованных детей; null даёт пустой компонент |
| `text.fromJson(json)` | `Text` | разбирает json текстового компонента (бросает `ScriptException` на пустом или невалидном) |

В `legacy` код цвета сбрасывает стиль до одного этого цвета, `§r` сбрасывает стиль целиком, а любой другой код добавляется к текущему стилю. Одиночный `§`, за которым нет валидного кода, остаётся литеральным символом.

## Оформление

| Метод | Тип | Описание |
|---|---|---|
| `color(argb)` | `Text` | цвет; байт альфы отбрасывается, берётся только RGB |
| `bold(value)` | `Text` | флаг жирного |
| `italic(value)` | `Text` | флаг курсива |
| `underlined(value)` | `Text` | флаг подчёркивания |
| `strikethrough(value)` | `Text` | флаг зачёркивания |
| `obfuscated(value)` | `Text` | флаг перемешанных глифов |
| `font(fontId)` | `Text` | id шрифта; без неймспейса подставляется `minecraft:` (бросает `ScriptException` на пустом или неразбираемом) |
| `append(Text)` | `Text` | добавляет другой компонент; null игнорируется (бросает `ScriptException`, если он собран не через `text.*`) |
| `append(String)` | `Text` | добавляет литеральную строку; null игнорируется |

Ребёнок, добавленный после вызова оформления, наследует этот стиль — как в ванили.

## Клики и ховеры

| Метод | Тип | Описание |
|---|---|---|
| `insertion(value)` | `Text` | что shift-клик вставит в поле ввода |
| `runCommand(command)` | `Text` | клик выполняет команду (бросает `ScriptException` на пустой строке) |
| `suggestCommand(command)` | `Text` | клик кладёт команду в поле ввода, не отправляя (бросает `ScriptException` на пустой строке) |
| `openUrl(url)` | `Text` | клик открывает ссылку; только http и https (бросает `ScriptException` на любой другой схеме) |
| `copyToClipboard(value)` | `Text` | клик копирует строку в буфер обмена (бросает `ScriptException` на пустой строке) |
| `hoverText(Text)` | `Text` | ховер-подсказка; null игнорируется (бросает `ScriptException`, если она собрана не через `text.*`) |
| `hoverText(String)` | `Text` | ховер-подсказка из литеральной строки; null игнорируется |
| `hoverItem(item)` | `Text` | карточка предмета; null, пустой и чужой стак игнорируются |
| `hoverEntity(entity)` | `Text` | ховер с типом, uuid и именем сущности (бросает `ScriptStateException`, если сущность покинула мир) |

Клики и ховеры срабатывают только у сообщения, которое лежит в чате; текст, нарисованный через `render`, не интерактивен.

## Чтение

| Метод | Тип | Описание |
|---|---|---|
| `copy()` | `Text` | глубокая копия компонента и его детей, менять безопасно |
| `string()` | `String` | плоский текст без кодов оформления |
| `toJson()` | `String` | json текстового компонента (бросает `ScriptException`, если закодировать не удалось) |

`toString()` возвращает то же, что и `string()`.
