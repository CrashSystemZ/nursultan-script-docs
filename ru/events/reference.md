# Список событий

51 событие, сгруппированы по областям. Все они приходят в основном потоке Minecraft, кроме `PacketReceiveEvent` и `PacketSendEvent`. Если у события нет таблицы членов — у него нет полезной нагрузки. Подписка, отмена и опции — в [Подписке](basics.md).

```kotlin
on<BlockHitEvent> {
    // верхнюю грань блока не бьём
    if (it.side() == Side.UP) it.cancel()
}
```

## Тики

| Событие | Отмена | Когда |
|---|---|---|
| `ClientTickEvent` | нет | раз в тик клиента, в том числе без загруженного мира |
| `PrePlayerTickEvent` | нет | раз в тик клиента, до тика локального игрока |
| `PlayerTickEvent` | нет | внутри тика игрока, на обновлении откатов |
| `PostPlayerTickEvent` | нет | после того как тик игрока закончился |
| `TimerEvent` | нет | раз в кадровый тик, до применения длительности тика |

### TimerEvent

| Метод | Тип | Описание |
|---|---|---|
| `timer()` | `float` | множитель скорости тиков клиента, 1.0 — норма |
| `timer(value)` | `void` | перезаписывает его; длительность тика делится на него, без ограничений |

Перед каждой отправкой сбрасывается в 1.0 и между кадрами не сохраняется; `0` даёт деление на ноль.

## Движение

| Событие | Отмена | Когда |
|---|---|---|
| `MoveInputEvent` | да (не читается) | каждый тик, после опроса клавиш движения |
| `MoveEvent` | да | перед тем как клиентская сущность применит вектор перемещения |
| `MovePacketEvent` | да | раз в тик, перед отправкой пакетов позиции и поворота |
| `MoveRelativeEvent` | нет | после того как ввод движения превратился в скорость |
| `TravelEvent` | да | перед ванильным шагом физики локального игрока |
| `JumpEvent` | нет | локальный игрок прыгает |
| `SlowdownEvent` | нет | игра запрашивает множитель скорости при использовании предмета |
| `FireworkEntitySpeedEvent` | нет | ракета разгоняет летящего в элитре, раз в тик на ракету (API 2) |
| `BlockPushEvent` | да | локального игрока собираются вытолкнуть из блока |
| `EntityPushEvent` | да | локальный игрок толкает сущность или она его |
| `WebCollisionEvent` | да | локальный игрок коснулся паутины |

### MoveInputEvent

|---|---|---|

| `backward()` | `boolean` | клавиша назад зажата |
| `backward(value)` | `void` | перезаписывает флаг назад; игра читает его заново |
| `left()` | `boolean` | клавиша шага влево зажата |
| `left(value)` | `void` | перезаписывает флаг влево; игра читает его заново |
| `right()` | `boolean` | клавиша шага вправо зажата |
| `right(value)` | `void` | перезаписывает флаг вправо; игра читает его заново |
| `jump()` | `boolean` | клавиша прыжка зажата |
| `jump(value)` | `void` | перезаписывает флаг прыжка; игра читает его заново |
| `sneak()` | `boolean` | клавиша приседания зажата |
| `sneak(value)` | `void` | перезаписывает флаг приседания; игра читает его заново |
| `sprint()` | `boolean` | клавиша спринта зажата |
| `sprint(value)` | `void` | перезаписывает флаг спринта; заодно двигает состояние клавиши спринта |
| `moving()` | `boolean` | true, если зажата любая из вперёд, назад, влево, вправо |
| `toInput()` | [`MoveInput`](../actions/prediction.md) | неизменяемый снимок семи флагов |

Игра пересобирает ввод игрока за тик из всех семи флагов. Отмена ванильный ввод не останавливает — миксин флаг не читает.

### MoveEvent

| Метод | Тип | Описание |
|---|---|---|
| `movement()` | [`Vec`](../game/math.md) | дельта перемещения в блоках для этого вызова |
| `movement(value)` | `void` | заменяет вектор целиком; игра читает его заново |
| `x()` | `double` | компонента X перемещения в блоках |
| `y()` | `double` | компонента Y перемещения в блоках |
| `z()` | `double` | компонента Z перемещения в блоках |
| `set(x, y, z)` | `void` | заменяет вектор покомпонентно; игра читает его заново |

Отмена выкидывает весь вызов перемещения: ни смещения, ни обработки коллизий.

### MoveRelativeEvent

|---|---|---|
| `speed()` | `float` | множитель скорости, применённый ко вводу |
| `input()` | [`Vec`](../game/math.md) | сырой ввод: x вбок, y вверх, z вперёд, каждый примерно -1..1 |

### SlowdownEvent

| `multiplier(value)` | `void` | перезаписывает его; возвращается вместо ванильного, без ограничений |

### FireworkEntitySpeedEvent

| Метод | Тип | Описание |
|---|---|---|
| `speed()` | `double` | множитель разгона элитры, ванильное значение 1.5 |
| `speed(value)` | `void` | перезаписывает разгон на этот тик; игра читает его заново |
| `firework()` | [`Entity`](../game/entities.md) | сама ракета |
| `shooter()` | [`LivingEntity?`](../game/entities.md) | тот, кого разгоняют, null если у ракеты его нет |

Приходит на любую ракету в мире, не только на твою.

### WebCollisionEvent

|---|---|---|

| `z()` | `int` | Z блока паутины |
| `position()` | [`Vec`](../game/math.md) | позиция блока вектором, копия |

Отмена убирает замедление от паутины.

## Бой

| Событие | Отмена | Когда |
|---|---|---|
| `AttackEvent` | да | перед тем как клиент ударит сущность |
| `AttackedEvent` | нет | после того как удар прошёл |
| `TargetUpdateEvent` | нет | боевая цель клиента сменилась или истекла |

### AttackEvent

| Метод | Тип | Описание |
|---|---|---|
| `target()` | [`Entity`](../game/entities.md) | сущность, которую сейчас ударят |

Отмена убирает удар целиком — ни взмаха, ни пакета, и откат атаки не сбрасывается.

### AttackedEvent

| Метод | Тип | Описание |
|---|---|---|
| `target()` | [`Entity`](../game/entities.md) | сущность, которую только что ударили |

### TargetUpdateEvent

| Метод | Тип | Описание |
|---|---|---|
| `previous()` | [`Entity?`](../game/entities.md) | цель до смены, null если её не было |
| `target()` | [`Entity?`](../game/entities.md) | новая цель, null если цель потеряна или истекла |
| `lost()` | `boolean` | true, когда `target()` равен null |

Публикует трекер целей клиента: без боевого модуля и без вызова `combat.markTarget(...)` событие не приходит.

## Блоки

### BlockBreakingEvent

| Метод | Тип | Описание |
|---|---|---|
| `breaking()` | `boolean` | true, пока зажата клавиша атаки |

Отмена выкидывает шаг копания за кадр целиком, вместе с остановкой брошенного копания.

### BlockHitEvent

### UseItemEvent

| Метод | Тип | Описание |
|---|---|---|

### FinishUsingItemEvent

## Ввод

| Событие | Отмена | Когда |
|---|---|---|
| `KeyEvent` | да | клавиша или кнопка мыши нажата, отпущена или повторяется |
| `CharEvent` | да | в окно введён символ |
| `MouseScrollEvent` | да | крутится колесо мыши |
| `LookInputEvent` | да | направление взгляда сущности меняется движением курсора |

### KeyEvent

| Метод | Тип | Описание |
|---|---|---|
| `key()` | [`Key`](../actions/keys.md) | нажатая клавиша или кнопка мыши, `Key.UNKNOWN` без константы |
| `mods()` | `int` | битовая маска модификаторов GLFW, 0 у синтетических событий |
| `action()` | [`KeyAction`](../actions/keys.md) | PRESS, RELEASE или REPEAT |
| `mouse()` | `boolean` | true для кнопок мыши |
| `pressed()` | `boolean` | true, когда действие PRESS |
| `released()` | `boolean` | true, когда действие RELEASE |
| `matches(other)` | `boolean` | true, когда константа клавиши та же |

Отмена не пускает клавишу в бинды и экраны Minecraft.

### CharEvent

| Метод | Тип | Описание |
|---|---|---|
| `codePoint()` | `int` | Unicode code point введённого символа |
| `character()` | `String` | code point строкой, 1 или 2 символа |
| `mods()` | `int` | битовая маска модификаторов GLFW во время ввода |

### MouseScrollEvent

| Метод | Тип | Описание |
|---|---|---|
| `vertical()` | `double` | вертикальная дельта колеса, положительная — вверх |
| `horizontal()` | `double` | горизонтальная дельта, 0 без наклонного колеса |

### LookInputEvent

| Метод | Тип | Описание |
|---|---|---|
| `deltaX()` | `double` | горизонтальная дельта курсора, на 0.15 даёт градусы yaw |
| `deltaX(value)` | `void` | перезаписывает горизонтальную дельту; игра читает её заново |
| `deltaY()` | `double` | вертикальная дельта курсора, на 0.15 даёт градусы pitch |
| `deltaY(value)` | `void` | перезаписывает вертикальную дельту; игра читает её заново |

Приходит для любой сущности, не только для локального игрока; отмена оставляет yaw и pitch нетронутыми.

### EffectEvent

### PlaySoundEvent

| Метод | Тип | Описание |
|---|---|---|
| `id()` | `String` | registry id звука, пустая строка если не определился |
| `category()` | `String` | категория звука в нижнем регистре, пустая строка если её нет |
| `volume()` | `float` | громкость звука, 1.0 — норма |
| `volume(value)` | `void` | перезаписывает громкость; звук читает её заново |
| `pitch()` | `float` | множитель высоты тона, ванильный диапазон 0.5..2.0 |
| `pitch(value)` | `void` | перезаписывает тон; звук читает его заново |
| `x()` | `double` | X источника звука в мировых блоках |
| `x(value)` | `void` | перезаписывает X источника; звук читает его заново |
| `y()` | `double` | Y источника звука в мировых блоках |
| `y(value)` | `void` | перезаписывает Y источника; звук читает его заново |
| `z()` | `double` | Z источника звука в мировых блоках |
| `z(value)` | `void` | перезаписывает Z источника; звук читает его заново |
| `position()` | [`Vec`](../game/math.md) | текущие x, y и z копией |
| `position(value)` | `void` | ставит x, y и z из вектора |

`id()` и `category()` только читаются. Событие приходит только на звуки, идущие через позиционный путь мира; отмена — звук не проигрывается.

## Пакеты

| Событие | Отмена | Когда |
|---|---|---|
| `PacketReceiveEvent` | да | клиентский пакет декодирован, до того как игра его обработает |
| `PacketSendEvent` | да | серверный пакет вот-вот уйдёт из клиента |

### PacketReceiveEvent

| Метод | Тип | Описание |
|---|---|---|
| `packet()` | [`S2CPacket`](../actions/packets.md) | декодированный пакет от сервера |

Работает на IO-потоке netty; внутри бандла каждый подпакет приходит отдельно, а отмена убирает его из бандла.

### PacketSendEvent

| Метод | Тип | Описание |
|---|---|---|
| `packet()` | [`C2SPacket`](../actions/packets.md) | декодированный пакет к серверу |

Работает на вызывающем потоке. У обоих событий до обработчика доходят только пакеты, которые клиент умеет декодировать, а `EventOptions` игнорируется.

| `RenderCrosshairEvent` | да | ванильный прицел вот-вот нарисуется (API 2) |
| `RenderItemEvent` | да | перед применением трансформации взмаха от первого лица |
| `BlockOutlineEvent` | да | перед отрисовкой обводки блока в прицеле |
| `SwingSpeedEvent` | нет | игра спрашивает, сколько длится взмах рукой |

### Render2DEvent

| Метод | Тип | Описание |
|---|---|---|
| `render()` | [`Render`](../ui/render-2d.md) | общая 2D-поверхность рисования |
| `tickDelta()` | `float` | доля прошедшего тика, 0..1 |
| `width()` | `float` | ширина фреймбуфера в физических пикселях, без GUI-масштаба |
| `height()` | `float` | высота фреймбуфера в физических пикселях, без GUI-масштаба |

### Render3DEvent

| Метод | Тип | Описание |
|---|---|---|
| `render()` | [`Render3D`](../ui/render-3d.md) | общая мировая поверхность рисования |
| `tickDelta()` | `float` | доля прошедшего тика, 0..1 |
| `camera()` | [`Vec`](../game/math.md) | позиция камеры в блоках, начало отсчёта для мировых рисовалок |
| `viewMatrix()` | `float[]` | 16 float, column-major, копия на каждый вызов (API 2) |
| `projectionMatrix()` | `float[]` | 16 float, column-major, копия на каждый вызов (API 2) |

Оба события отрисовки игнорируют `EventOptions` и не приходят, если на них никто не подписан; `Render3DEvent` вдобавок требует загруженного мира.

### CameraEvent

| Метод | Тип | Описание |
|---|---|---|
| `yaw()` | `float` | yaw камеры в градусах, интерполирован по tick delta |
| `yaw(value)` | `void` | перезаписывает yaw камеры; применяется к камере |
| `pitch()` | `float` | pitch камеры в градусах, интерполирован по tick delta |
| `pitch(value)` | `void` | перезаписывает pitch камеры; применяется к камере |
| `x()` | `double` | X камеры в мировых координатах, интерполирован |
| `x(value)` | `void` | перезаписывает X камеры; применяется к камере |
| `y()` | `double` | Y камеры в мировых координатах, вместе со смещением глаз |
| `y(value)` | `void` | перезаписывает Y камеры; применяется к камере |
| `z()` | `double` | Z камеры в мировых координатах, интерполирован |
| `z(value)` | `void` | перезаписывает Z камеры; применяется к камере |
| `position()` | [`Vec`](../game/math.md) | текущие x, y и z копией |
| `position(value)` | `void` | ставит x, y и z из вектора |

Отмена пропускает остаток обновления камеры — дистанцию в третьем лице и подрезку, — но выставленные здесь значения всё равно применяются.

### PerspectiveEvent

| Метод | Тип | Описание |
|---|---|---|
| `previous()` | [`Perspective`](../actions/control.md#настройки-игры) | вид до смены, никогда не null |
| `current()` | [`Perspective`](../actions/control.md#настройки-игры) | вид после смены, никогда не null |

Установка того же самого вида событие не рождает.

### RenderItemEvent

| Метод | Тип | Описание |
|---|---|---|
| `arm()` | [`Arm`](../game/inventory.md) | какая рука рисуется, LEFT или RIGHT |
| `swingProgress()` | `float` | прогресс анимации взмаха, 0..1 |

Отмена оставляет матрицу в начале руки, так что трансформация взмаха для этой руки пропускается.

### BlockOutlineEvent

| Метод | Тип | Описание |
|---|---|---|
| `x()` | `int` | X обводимого блока в мировых координатах |
| `y()` | `int` | Y обводимого блока в мировых координатах |
| `z()` | `int` | Z обводимого блока в мировых координатах |
| `box()` | [`Box`](../game/math.md) | форма обводки, смещённая в абсолютные мировые координаты |

Приходит только когда есть обводка с непустой формой, и раньше обоих событий отрисовки того же кадра.

### SwingSpeedEvent

| Метод | Тип | Описание |
|---|---|---|
| `durationTicks()` | `int` | длина анимации взмаха в тиках, ванильная база 6 |
| `durationTicks(value)` | `void` | перезаписывает длину; возвращается игре, без ограничений |

Только локальный игрок; на это число делится прогресс взмаха.
